# Sojourn

A multi-role academic management portal built for the Instituto de Lengua Española (ILE) as a supervised 320-hour professional internship (Práctica Empresarial Supervisada).

> Note: This repository is private due to an institutional agreement with ILE. Screenshots and a walkthrough are available on request.

## Features
- Role-based access control across Admin, Teacher, and Student roles
- Enrollment, grading, and course management workflows
- REST API for all core academic operations

## Tech Stack
- **Frontend:** React (Vite)
- **Backend:** Node.js, Express
- **Database:** MySQL (deployed via JawsDB)
- **Auth:** JWT
- **Hosting:** Heroku

## About
Built from scratch as part of a supervised internship, including all core database tables and role-based workflows. Delivered under regular formal progress reporting to a university supervisor and external coordinator.
